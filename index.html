Select Folder

Select your
target folder.

Pick the workspace subfolder inside .openclaw — not the .openclaw folder itself. This is the #1 mistake, so double-check.

CRITICAL — Select this exact folder:
~/.openclaw/workspace

Not ~/.openclaw alone. The workspace subfolder inside it.
.openclaw is a hidden folder. Here's how to reveal it:

Mac (Finder): Press Cmd + Shift + . to toggle hidden files, then navigate to your home folder and open .openclaw → workspace.

Windows (Explorer): Click View → check "Hidden items", then go to C:\Users\YourName\.openclaw\workspace.

Linux: Press Ctrl + H in your file manager to show hidden folders, then open .openclaw → workspace.

Select your ~/.hermes folder. That's where Hermes keeps its config — the installer will write your profile files directly into it. No terminal needed.

Select this exact folder:
~/.hermes

This is where SOUL.md, MEMORY.md, and USER.md will be written.
.hermes is a hidden folder. Here's how to reveal it:

Mac (Finder): Press Cmd + Shift + . to toggle hidden files, then navigate to your home folder and select .hermes.

Windows: Click View → check "Hidden items", then go to C:\Users\YourName\.hermes.

Linux: Press Ctrl + H in your file manager to show hidden folders, then select .hermes.
Zero terminal install. For Hermes, the browser writes your profile files directly — no copy-paste command required at the end.

Hermes Agent Setup

          
Install Hermes
in 60 seconds.

          
Run this command in your terminal. It installs Hermes, sets up your config folder, and gets you ready to install agent profiles.


          

            

              

                Install Command
                macOS / Linux / WSL
              

              
            

            

              
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

            

          


          

            After installing, run: hermes setup to configure your AI provider and API key. Then come back here to install your agent profile.
          

          

            Don't have an API key? OpenRouter gives you access to 200+ models (Claude, GPT-4, Gemini…) with a single key.
          

          

            Windows: Hermes requires WSL (Windows Subsystem for Linux). Install WSL first, then run the command above inside it.
